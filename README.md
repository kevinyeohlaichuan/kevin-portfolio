# Kevin Yeoh — Portfolio

Public portfolio for Kevin Yeoh and Eternal Amaris Universe.

The site presents two clearly separated professional lanes:

- production full-stack and interactive 3D web work;
- released and in-development games under Spicy MSG Studio.

## Public project boundaries

- HauS on 15 / Gamuda SS15 is presented as solo engineering with supplied visual assets.
- GoProp.ai is presented as shared company work with Kevin's contribution lane stated explicitly.
- No private company source code or unreleased client assets are included.
