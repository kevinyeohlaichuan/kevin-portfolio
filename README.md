# Kevin Yeoh — EAU Portfolio

Public portfolio for Kevin Yeoh and Eternal Amaris Universe.

The site presents Kevin's work across three connected lanes:

- full-stack architectural-visualisation delivery;
- interactive 3D systems for GoProp Pro, Web and Platform;
- released and in-development games under Spicy MSG Studio.

V2 adds an animated EAU visual system, interactive line-art product previews,
click-to-load live products, game micro-demos and a shareable digital card.

## Public project boundaries

- HauS on 15 / Gamuda SS15 is presented as Kevin's end-to-end implementation across frontend, backend, database, 3D pipeline and deployment.
- GoProp's three solution lanes are described using the company's public marketing language.
- Unreal showroom experience is described as professional experience, not claimed as an individually authored public showcase.
- No private company source code or unreleased client assets are included.
