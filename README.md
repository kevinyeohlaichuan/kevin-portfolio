# Kevin Yeoh's Portfolio

[View the live website](https://eternalamarisuniverse.com/)

I am a full-stack developer in Kuala Lumpur. I work on architectural visualisation, interactive 3D web and games.

This repository contains the public portfolio pages I am comfortable sharing: Home, Professional, Games and About.

The Universe tab is a separate product area on the same website. Its source, writing and original assets live in private repositories.

## What is in here

- Interactive architectural previews built with Babylon.js
- Small playable game samples built with Phaser
- Astro pages with React for the interactive parts
- A server-side contact form with validation and spam protection

The main stack is Astro, React, TypeScript, Babylon.js, Phaser, GSAP and Cloudflare Workers.

## Run it locally

You need Node.js 22 or newer.

```bash
npm ci
npm run dev
```

Run `npm test` to check the production build.

## AI-assisted development

I use AI tools to help implement and debug this site. I decide what it should do, test the real result, report what is wrong and decide what is ready to ship. I do not claim that I manually typed every line.
