You are not the protagonist. You are the System bolted onto one — issuing
priorities and watching an autonomous host interpret them, succeed, fail,
and occasionally do something you did not intend.

The loop is: set a priority (搜 seek, 打 engage, 割 harvest), let the host
run, then read what actually happened and adjust. The interesting design
space is the gap between what you asked for and what the host did.

Set in the [Eternal Amaris Universe](/universe).
