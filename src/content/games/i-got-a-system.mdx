You are not the protagonist. You are the System attached to one. Set up the
host, start a dungeon level, and watch the turn-based run play automatically.

Each level uses a small or large checkerboard formation with procedural
chests, basic enemies, elites and bosses. Enemies can carry different elements,
drop rates and attack styles. The host gains levels, experience, stats,
equipment, inventory items and combat skills without a fixed level cap.

After every run, the player reviews the host: too greedy, too cautious, or not
willing enough to fight. Those commands slowly form the host&rsquo;s behaviour.
The System earns points for upgrades or rewards. Death reduces the host&rsquo;s
lifespan, while repeated deaths or withheld rewards can reduce obedience until
the host sometimes acts outside the player&rsquo;s intended pattern.

Progress is stored locally so a run can resume on the same device. When a
host&rsquo;s lifespan ends, the record keeps the host level, System level and
highest dungeon reached.

This is a private work in progress made with a small team.
