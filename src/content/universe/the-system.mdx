A System attaches to a host and can express priority, but not control. It
says *seek*, *engage*, *harvest* — 搜, 打, 割 — and the host interprets.

The gap between the priority and the interpretation is the whole
relationship. A host is not a puppet and a System is not an author.

Explored directly in [I Got a System](/games/i-got-a-system).
